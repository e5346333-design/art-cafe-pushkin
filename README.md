# Арт-кафе «Пушкин» — сайт

Одностраничный сайт арт-кафе «Пушкин» (станица Варениковская): меню с корзиной,
оформление заказа, доставка, бронирование стола, отзывы и контакты.
Чистый HTML + CSS + JS, без сборки и зависимостей — файлы можно выкладывать как есть.

## Что загружать

| Файл / папка | Назначение |
| --- | --- |
| `index.html` | Главная страница (точка входа) |
| `styles.css` | Все стили |
| `script.js` | Меню, корзина, заказ, бронирование |
| `assets/hall.jpg` | Фото зала (первый экран + блок «О кафе») |
| `assets/coffee.jpg` | Фото капучино (блок «Доставка») |
| `pushkin-onefile.html` | Необязательно: автономная версия со встроенными картинками и стилями |
| `tools/build-onefile.ps1` | Пересобирает `pushkin-onefile.html` из `index.html`, `styles.css`, `script.js` и картинок |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |
| `shot-*.png` | Скриншоты для проверки вёрстки — на сайт не нужны |

`pushkin-onefile.html` собирается командой (нужен только PowerShell, без Node.js):

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-onefile.ps1
```

Запускайте её после правок в `index.html`, `styles.css` или `script.js`, иначе автономная
версия останется устаревшей. Для публикации на GitHub Pages она не нужна — там достаточно
`index.html` + `styles.css` + `script.js` + `assets/`.

## Публикация на GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `pushkin-site`), публичный.
2. Загрузите в него файлы из списка выше (`Add file` → `Upload files`).
3. `Settings` → `Pages` → `Source: Deploy from a branch` → `Branch: main`, папка `/ (root)` → `Save`.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/pushkin-site/`.

Проверка локально: откройте `index.html` двойным щелчком либо запустите
`python -m http.server 8000` в папке проекта и зайдите на `http://localhost:8000`.

## Что стоит заменить перед публикацией на своём домене

- `og:image` в `index.html` — указать полный адрес картинки (`https://ваш-домен/assets/hall.jpg`),
  иначе Telegram и VK не покажут превью.
- Ссылки на Telegram (`t.me/artcafepushkin`), телефон и адрес — если что-то изменилось.

## Что уже учтено в вёрстке

- Текст на странице не пропадёт, если JS не загрузился (класс `no-js` + `<noscript>`).
- Статус «Открыто до 22:00 / 23:00» считается по московскому времени, а не по часам посетителя.
- В форме брони нельзя выбрать прошедшую дату, сегодняшняя подставляется по местному времени.
- В корзине честный итог: самовывоз, доставка оплачивается отдельно.
- У картинок заданы `width`/`height` (нет скачков вёрстки), первая картинка предзагружается.

## Как устроены заказ и бронь

Сайт статический, без сервера и базы данных:

- **Заказ** собирается в корзине (`localStorage`), на экране оформления выводится готовый
  текст заказа: его копируют и отправляют в Telegram или диктуют по телефону.
- **Бронь** стола формируется в модальном окне и после отправки открывается чат Telegram
  с уже скопированным текстом заявки.

Если позже понадобится автоматическая отправка заявок, можно подключить внешний
сервис (Formspree, Getform, Telegram Bot API через Cloudflare Worker) — правки локальны
в `script.js`.
